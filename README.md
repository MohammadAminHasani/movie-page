# Blade Runner (1982) Movie Introduction Page

A simple movie introduction webpage built with **HTML5**.
This project presents information about *Blade Runner (1982)*, including its story, cast, ratings, visual style, soundtrack, and famous quote.

## Features

* Movie poster and visual images
* IMDb, Rotten Tomatoes, and Letterboxd ratings
* Overview and summary sections
* Quick facts about the movie
* Main cast information
* Visual style showcase
* Soundtrack description 
* Famous quote section
* Online watching links 

## Built With

* HTML5

## About The Movie

*Blade Runner (1982)* is a science fiction film directed by **Ridley Scott**. Set in a futuristic and dystopian Los Angeles, the movie explores themes such as artificial intelligence, identity, memory, and what it means to be human.

The film is widely considered one of the most influential works in the cyberpunk genre, known for its unique atmosphere, neon visuals, and legendary soundtrack by **Vangelis**.
